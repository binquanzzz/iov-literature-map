# 车联网安全代码生成 · 文献脑图

基于35篇已调研文献整理的交互式脑图，保留原始HTML样式。

- `index.html`：独立运行的交互网页（内含样式、脚本与文献数据）。
- `literature.json`：可复用的文献条目、分类和关联数据。
- `文献梳理.md`：便于阅读和修订的文字版。
- `.nojekyll`：使用原生静态页面发布。

## 后续增加文献

阅读新文献后补充方法、证据、局限、来源页码、分类与关联，并同步更新网页中的内嵌文献数据、统计及文字版。仅修改 `literature.json` 不会自动改变当前网页。提交更新到 `main` 后，GitHub Pages 自动重新发布。

原始PDF不包含在本站中；文献结论与研究迁移设想在阅读卡片中分别标记。
